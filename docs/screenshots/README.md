# Capturas de pantalla para GitHub

Coloca aquí imágenes PNG o GIF que muestren la interfaz de SManager 2.0.

## Archivos recomendados

| Archivo | Contenido |
|---------|-----------|
| `01-inicio.png` | Panel de control (dashboard) |
| `02-asistente.png` | Asistente de configuración |
| `03-sincronizacion.png` | Tarjetas de pares origen → destino |
| `04-analizar-cambios.png` | Diálogo de vista previa |
| `05-monitor.png` | Monitor en tiempo real |
| `06-registro.png` | Registro con filtros |
| `07-estadisticas.png` | Panel de estadísticas |
| `demo.gif` | GIF 10–20 s: asistente → analizar → iniciar → progreso |

## Cómo enlazarlos en el README principal

```markdown
![Panel de control](docs/screenshots/01-inicio.png)
```

## Consejo

Usa el tema claro u oscuro de Windows de forma consistente en todas las capturas.
